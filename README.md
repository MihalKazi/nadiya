# nadiya

Portfolio site for **Nadiya Nusrat** — nutrition, public health, and health communication.

## Project structure

- `web/` — Next.js site (run with `npm install` && `npm run dev`)
- `preview (2).html` — original static preview
- `scripts/extract-articles.mjs` — regenerate article JSON from HTML

## Quick start

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Live site:** https://nadiya-six.vercel.app
