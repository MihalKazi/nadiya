# Nadiya Nusrat — Portfolio

Professional portfolio site built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Content

- Site copy: `src/data/site.ts`
- Articles: `src/data/articles.json` (regenerate from `preview (2).html` with `node ../scripts/extract-articles.mjs`)

## Deploy

Deploy the `web` folder to [Vercel](https://vercel.com) or any Node host that supports Next.js.
